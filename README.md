# AI-Enhanced Smart Task Manager

A modern, intelligent task manager built using the MERN stack (MongoDB, Express, React, Node.js).  
This system simplifies productivity by offering task creation, smart prioritization, reminders, analytics, and clean UI.

---

## 🚀 Features
- User Authentication (Signup/Login)
- Create, Edit, Delete Tasks
- AI-Based Priority Scoring
- Smart Reminders & Notifications
- Task Search & Filters
- Analytics Dashboard
- Fully responsive UI

---

## 🧠 Tech Stack
**Frontend:** React, Context API  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Tools:** JWT Auth, Bcrypt, Git, VS Code
